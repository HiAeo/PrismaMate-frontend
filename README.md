# PrismaMate Frontend - Vue 3 前端

## 技术栈

- Vue 3 + Composition API
- TypeScript
- Vite
- Element Plus
- Pinia (状态管理)
- Vue Router
- Axios
- ECharts

## 安装依赖

```bash
npm install
```

## 开发模式

```bash
npm run dev
```

## 构建生产版本

```bash
npm run build
```

## 项目结构

```
src/
├── api/          # API 请求封装
├── assets/       # 静态资源
├── components/   # 公共组件
├── router/      # 路由配置
├── stores/       # Pinia 状态管理
├── views/        # 页面组件
├── App.vue       # 根组件
└── main.ts       # 入口文件
```
