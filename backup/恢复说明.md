# PrismaMate v1.0.0 备份恢复说明

## 备份时间
2026-05-16

## 备份内容
- `prismamate-frontend_v1.0.0.zip` - 前端源码（不含node_modules）
- `prismamate-backend_v1.0.0.zip` - 后端完整代码

## 恢复步骤

### 前端恢复
```powershell
# 1. 解压到临时目录
Expand-Archive -Path "prismamate-frontend_v1.0.0.zip" -DestinationPath "d:\PrismaMate专用文件夹\prismamate-frontend-temp"

# 2. 备份当前版本（可选）
Move-Item "d:\PrismaMate专用文件夹\prismamate-frontend" "d:\PrismaMate专用文件夹\prismamate-frontend-current-backup"

# 3. 移动恢复
Move-Item "d:\PrismaMate专用文件夹\prismamate-frontend-temp" "d:\PrismaMate专用文件夹\prismamate-frontend"

# 4. 安装依赖
cd "d:\PrismaMate专用文件夹\prismamate-frontend"
npm install
```

### 后端恢复
```powershell
# 1. 解压
Expand-Archive -Path "prismamate-backend_v1.0.0.zip" -DestinationPath "d:\PrismaMate专用文件夹\prismamate-backend-temp"

# 2. 备份当前版本（可选）
Move-Item "d:\PrismaMate专用文件夹\prismamate-backend" "d:\PrismaMate专用文件夹\prismamate-backend-current-backup"

# 3. 移动恢复
Move-Item "d:\PrismaMate专用文件夹\prismamate-backend-temp" "d:\PrismaMate专用文件夹\prismamate-backend"

# 4. 安装依赖
cd "d:\PrismaMate专用文件夹\prismamate-backend"
pip install -r requirements.txt
```
